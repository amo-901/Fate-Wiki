# Fate / Domination Wiki

A database for easily accessible data to the characters in the tabletop game Fate / Domination.

## ✨ Features

- **Core Feature 1:** Comprehensive grid of playable Servant characters.
- **Core Feature 2:** Detailed information of character abilities, and resource cards. 
- **Responsive Design:** Works across mobile, desktop, and web.
